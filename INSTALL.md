# 🧑‍🎓 Установка: короткий урок и промпт для ИИ-агента

Руками тут почти ничего делать не нужно. Скачать, установить, настроить и проверить может ИИ-агент (Codex, Claude Code, Cursor — любой, который запускает команды на машине). От тебя нужны только вещи, до которых агент не дотянется: несколько нажатий в Telegram, вход в свои аккаунты и ключи.

**Как пользоваться:** открой агента на той машине, где будет жить бот, и отправь ему промпт из раздела [«Промпт для агента»](#промпт-для-агента). Дальше он ведёт сам.

## Урок на три минуты

### Из чего состоит

| Кусок | Что делает | Откуда берётся |
| --- | --- | --- |
| **Codex CLI** | Сам ИИ-агент, который выполняет задачи | `npm install -g @openai/codex` + вход аккаунтом ChatGPT (Plus или выше) |
| **Codex daemon** | Фоновый Codex, к которому подключается бот | Входит в Codex CLI, бот запускает его сам |
| **Этот бот** | Мост между Telegram и Codex | Этот репозиторий |
| **Telegram-бот** | Твой личный бот в Telegram | [@BotFather](https://t.me/BotFather), бесплатно |
| **Расшифровка голоса** | Превращает голосовые в текст | Ключ OpenAI (рекомендуется) или бесплатная локальная модель |
| **Свой Local Bot API** | Файлы больше 20 МБ: до 2000 МБ в обе стороны | Официальный сервер Telegram, ставится скриптом; ключи с my.telegram.org |

### Где ставить

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| **VPS с Ubuntu 22.04/24.04** (рекомендуется) | Работает круглосуточно, задачи идут, даже когда ноутбук закрыт | Нужен сервер (от ~5 $/мес, 2 ГБ RAM и больше) |
| **Mac** | Ничего не арендовать, Codex видит твои локальные файлы | Бот работает, только пока Mac включён и не спит |
| **Windows** | Через WSL2 (Ubuntu) — как Linux | Родной Windows не поддерживается |

Бот и Codex всегда на одной машине: задачи выполняются там же, где стоит бот.

## Что сделать тебе (агент подскажет, когда)

### Шаг 1. Создай бота

1. Открой в Telegram [@BotFather](https://t.me/BotFather) (с синей галочкой).
2. Отправь `/newbot`, придумай имя и username, который заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `123456789:AAH...`. Передай его агенту. Никому больше его не показывай.
4. Открой своего нового бота и нажми **Start**: без этого бот не сможет тебе написать.

### Шаг 2. Включи темы (Threaded Mode)

Это обязательная настройка: без неё бот не сможет раскладывать чаты по темам.

> ⚠️ Темы включаются **только в мини-приложении BotFather**. Командами (`/mybots`, `/setcommands` и другими) в чате с BotFather этого не сделать, и боту командами тоже.

1. Открой чат с [@BotFather](https://t.me/BotFather).
2. Нажми кнопку **Open** (рядом с полем ввода или в профиле BotFather). Откроется мини-приложение.
3. **My bots** → выбери своего бота.
4. **Bot Settings** → **Threads Settings**.
5. Включи **Threaded Mode**. Разрешение пользователям создавать темы оставь включённым.

Проверка: агент запустит `npm run doctor`, там должна быть строка `✅ Threaded Mode`. Если после включения бот уже был запущен, он сам подхватит темы, перезапуск не нужен.

### Шаг 3. Узнай свой Telegram ID

Открой [@userinfobot](https://t.me/userinfobot), нажми **Start**: он пришлёт число `Id`. Передай его агенту. Бот будет слушаться только этого ID.

### Шаг 4. Войди в Codex

Агент запустит `codex login`. На компьютере откроется браузер, на сервере без экрана он запустит `codex login --device-auth` и покажет ссылку с кодом: открой её на телефоне или ноутбуке и войди своим аккаунтом ChatGPT (нужна подписка Plus, Pro, Business или выше). Перед входом по коду включи его в ChatGPT: аватар → **Settings → Security** → **Enable device code authorization for Codex** (в рабочем аккаунте Business/Enterprise это включает администратор).

Нет подписки: Codex работает и с API-ключом OpenAI (`codex login --with-api-key`), тогда оплата идёт по факту использования.

### Шаг 5. Выбери, как расшифровывать голосовые

**Вариант 1 — OpenAI (рекомендуется):** лучшее качество, несколько секунд на сообщение, примерно $0,006 за минуту голоса.

1. Зайди на [platform.openai.com](https://platform.openai.com) и войди (аккаунт тот же, что в ChatGPT, но баланс API отдельный от подписки).
2. **Settings → Billing** ([прямая ссылка](https://platform.openai.com/settings/organization/billing/overview)) → **Add payment details** → привяжи карту и пополни баланс. Минимум $5, их хватит примерно на 13 часов голосовых.
3. **API keys** ([прямая ссылка](https://platform.openai.com/api-keys)) → **Create new secret key** → скопируй ключ `sk-...` (он показывается один раз) и передай агенту.

**Вариант 2 — бесплатно и локально:** агент соберёт [whisper.cpp](https://github.com/ggml-org/whisper.cpp) и скачает модель **NVIDIA Parakeet TDT 0.6B v3** (~0,7 ГБ, понимает русский, английский и ещё 23 европейских языка). Ничего не уходит в интернет, но скорость зависит от процессора, а сборка занимает 5–15 минут. Подробности и другие модели — в [docs/VOICE.md](docs/VOICE.md).

Голосовые можно подключить и позже. Текст и файлы работают без них.

### Шаг 6. Ключи для больших файлов

Через обычный (облачный) Telegram боты получают файлы только до **20 МБ** и отправляют до **50 МБ**. Чтобы слать боту видео, архивы и записи созвонов до **2000 МБ**, агент поставит рядом с ботом официальный сервер Telegram. Для него нужны ключи приложения:

1. Открой [my.telegram.org](https://my.telegram.org) на компьютере, введи номер телефона (`+7...`) — код придёт в Telegram.
2. **API development tools** → App title любое (`My files bot`), Short name — латиницей 5–32 символа (`myfilesbot`), Platform — `Other` → **Create application**.
3. Передай агенту **App api_id** (число) и **App api_hash** (32 символа).

Если форма отвечает `ERROR`, выключи VPN и блокировщик рекламы или попробуй другой браузер. Подробнее — [docs/LOCAL-BOT-API.md](docs/LOCAL-BOT-API.md). Шаг можно пропустить и сделать позже: всё остальное работает и без него.

## Промпт для агента

Скопируй целиком:

```text
Установи мне Codex Telegram Bot: https://github.com/artemmarketolog/codex-telegram-bot
Ставь на эту машину. Клонируй репозиторий в ~/codex-telegram-bot и выполни
раздел «Для ИИ-агента» из его INSTALL.md по шагам, проверяя результат каждого шага.
Всё, что можешь сделать сам, делай сам. Меня зови только за токеном бота,
моим Telegram ID, входом в Codex, ключами (OpenAI, my.telegram.org) и нажатиями в Telegram.
Секреты храни только в .env и никогда не показывай их в ответах.
```

## Для ИИ-агента

Ты ставишь бота пользователю, который может не быть программистом. Объясняй коротко и по-человечески. После каждого шага проверяй результат командой, а не на глаз. Не печатай значения токенов и ключей: ни в ответах, ни в логах, ни в командах с `echo`. Записывай их в `.env` так, чтобы значение не попало в вывод.

1. **Система.** Определи ОС (`uname -s`). Linux и macOS поддерживаются. Для Windows предложи WSL2 (Ubuntu) или VPS и остановись.
2. **Базовые пакеты.**
   - Ubuntu/Debian: `sudo apt-get update && sudo apt-get install -y git curl ffmpeg`.
   - macOS: нужен [Homebrew](https://brew.sh), затем `brew install git ffmpeg`.
3. **Node.js 22.13 или новее.** Проверь `node --version`.
   - Ubuntu/Debian: `curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - && sudo apt-get install -y nodejs`. Обычный `apt install nodejs` ставит слишком старую версию — не используй его.
   - macOS: `brew install node`.
   - Если Node стоит через nvm, это тоже подходит; новая версия: `nvm install 22`.
4. **Codex CLI.** Проверь `codex --version`. Если нет: `npm install -g @openai/codex` (при `EACCES` на Linux — `sudo npm install -g @openai/codex`). Затем `codex login status`. Если вход не выполнен, попроси пользователя войти (шаг 4 урока выше): на сервере без браузера сначала попроси включить device code authorization в настройках ChatGPT (шаг 4 урока), затем запусти `codex login --device-auth` и передай пользователю ссылку и код из вывода. Дождись `Logged in`.
5. **Бот.** `git clone https://github.com/artemmarketolog/codex-telegram-bot.git ~/codex-telegram-bot && cd ~/codex-telegram-bot && npm install && cp .env.example .env && chmod 600 .env`. Для уверенности прогони `npm test` (около минуты, всё должно пройти).
6. **Telegram.** Проведи пользователя по шагам 1–3 урока выше: создать бота, **включить Threaded Mode в мини-приложении BotFather** (не командами), узнать свой ID, нажать Start в своём боте. Впиши в `.env` `TELEGRAM_BOT_TOKEN` и `TELEGRAM_OWNER_ID`.
7. **Голосовые.** Спроси, какой вариант нужен (шаг 5 урока), и порекомендуй OpenAI.
   - OpenAI: проведи по шагам платформы, впиши `OPENAI_API_KEY` в `.env`.
   - Бесплатно: `bash scripts/install-local-stt.sh` (по умолчанию Parakeet v3; на Linux нужны `cmake g++ make`: `sudo apt-get install -y cmake g++ make`; на macOS — `xcode-select --install` и `brew install cmake`). Скрипт сам запишет `LOCAL_STT_CLI` и `LOCAL_STT_MODEL` в `.env`.
8. **Проекты.** Спроси, в каких папках Codex будет работать. Создай `projects.json` по образцу `projects.example.json` с абсолютными путями существующих папок и впиши основную папку в `DEFAULT_PROJECT` в `.env`. Если пользователь не знает, создай `~/workspace` и укажи её. Папки уже существующих чатов Codex бот подхватит сам.
9. **Самопроверка.** `npm run doctor -- --start-daemon`. Добивайся, чтобы все строки были ✅ (⚠️ про голосовые и большие файлы допустимо, если пользователь отложил их). Каждая ❌ содержит, что сделать. После шага 10 запусти doctor ещё раз.
10. **Большие файлы (рекомендуется).** Проведи пользователя по шагу 6 урока и впиши `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` в `.env`. Linux: `sudo apt-get install -y make git zlib1g-dev libssl-dev gperf cmake g++`. Затем `bash scripts/install-local-bot-api.sh` (сборка 20–60 минут; не прерывай её и не запускай второй раз параллельно). Скрипт сам запустит сервер, один раз переведёт бота с облачного API и впишет `TELEGRAM_API_BASE` в `.env`. Если скрипт попросит добавить swap — добавь командой из его сообщения и запусти снова. **После этого никогда не обращайся с токеном бота к `api.telegram.org`** (даже `curl .../getMe`): бот выпадет со своего сервера. Если пользователь отказался — пропусти шаг, бот работает с лимитом 20/50 МБ.
11. **Автозапуск.** `bash scripts/install-service.sh`. На Linux это systemd-сервисы пользователя с linger (бот переживает выход из SSH и перезагрузку), на macOS — launchd. Проверь:
    - Linux: `systemctl --user is-active codex-telegram.service codex-daemon-ensure.timer` → `active`; `journalctl --user -u codex-telegram -n 20 --no-pager` содержит `"event":"ready"`.
    - macOS: `launchctl list | grep codex`; в `~/Library/Logs/codex-telegram/bot.log` есть `"event":"ready"`.
    - Запускай бота только одним способом: если он уже работает как сервис, не запускай `npm start` параллельно (Telegram ответит ошибкой 409).
12. **Живая проверка вместе с пользователем.** Попроси написать боту в общий чат: «Создай файл test.txt со словом привет и пришли его мне». Должны появиться новая тема, карточка хода, ответ и файл. Потом — голосовое в эту же тему, а если ставил Local Bot API — файл больше 20 МБ (например, видео). Если что-то не так, смотри логи (шаг 10) и [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
13. **Итог.** Коротко расскажи пользователю, как пользоваться: писать в общий чат, одна тема — один чат, `/stop`, `/model`, `/chats`. Покажи, где логи и как перезапустить: Linux — `systemctl --user restart codex-telegram`, macOS — `launchctl kickstart -k gui/$(id -u)/local.codex-telegram`.

## Частые вопросы

**Нужна ли подписка ChatGPT?** Для Codex нужна подписка Plus или выше, либо API-ключ OpenAI с оплатой по факту. Для голосовых — отдельный баланс API или бесплатная локальная модель.

**Можно поставить на Vercel или Netlify?** Нет. Бот — постоянно работающий процесс рядом с Codex и твоими файлами. Для круглосуточной работы нужен VPS.

**Бот увидит мои чаты из приложения Codex?** Да, если приложение работает с тем же Codex (на этой же машине или подключено к серверу по SSH). Новые чаты оттуда сами получают тему в течение минуты, старые открываются через `/chats`.

**Сколько это стоит?** Бот бесплатный. Codex — по твоей подписке. Голосовые через OpenAI — около $0,006 за минуту; локально — бесплатно.

**Агент застрял?** Дай ему вывод `npm run doctor` и последние строки лога и попроси разобраться по [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
